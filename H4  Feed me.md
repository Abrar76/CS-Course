# x) . Feed reader.

A feed reader is an application that collects updates from different websites in one place. It uses RSS (Really Simple Syndication) or Atom feeds to receive new articles automatically.

Without a feed reader, we would have to visit every website separately to check for new content. With a feed reader, we can subscribe to multiple websites and see their latest articles in one application.

# y) . Supreme court of Finland Summary ( case Osuuspankkikeskus port scan KKO:2003:36)

The case KKO:2003:36 concerned an attempted computer intrusion against Osuuspankkikeskus (OPK).

A person used a computer program to perform a port scan against OPK's network. The purpose was to find open proxy servers that could potentially be used to access the network.
The scan did not get through the firewall, but the Supreme Court still considered the activity an attempted computer intrusion. The court also decided that the compensation should not be reduced.

What I learned: Port scanning can have legal consequences depending on its purpose and circumstances. Even if someone does not successfully enter a computer system, attempting to find security weaknesses for unauthorized access can be considered a criminal attempt.

# f). Port scan.
A port scanner is a tool used to check which ports are open, closed or filtered on a computer or network. It helps identify what services are running on a system. It can be used by network administrators to check security, but attackers can also use it to find possible vulnerabilities.
